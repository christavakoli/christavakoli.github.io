How it works & FAQ

What JSON can I convert to CSV?

Enter a nonempty array of objects, such as [{"name":"Ada"}]. The tool gathers columns from all objects. Nested arrays and objects become JSON text inside CSV cells.

Does CSV support commas and line breaks?

Yes. Quoted fields can contain commas, line breaks, and escaped double quotes. The first CSV row supplies the column names.

Are numbers automatically detected in CSV?

No. CSV cells become JSON strings, which preserves values such as ZIP codes with leading zeroes.
