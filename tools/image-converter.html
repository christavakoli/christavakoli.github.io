    How it works & FAQ

    How do I convert multiple images?

    Select several files and an output format. One result downloads directly; multiple results download together in a ZIP.

    Can I export AVIF?

    Only if your browser supports AVIF encoding through Canvas. If it does not, the tool displays an error rather than silently saving another format.

    What happens to EXIF information?

    The image is decoded and re-encoded using Canvas. Source EXIF metadata is not copied to the output. Keep the original if you need its metadata.
